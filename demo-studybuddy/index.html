📡 What Is a DDoS Attack?

DDoS (Distributed Denial of Service) is a malicious attempt to disrupt normal network traffic by overwhelming the target with a flood of Internet traffic from compromised botnet devices.

  • Volumetric: UDP / ICMP flood
  • Protocol: SYN Floods
  • Application: HTTP GET / POST Floods
